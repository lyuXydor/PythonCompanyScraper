# Python Web Scraper

\# Python Web Scraper



A Python web scraping tool built with Requests and BeautifulSoup.



\## Features



\- Scrape website data using Python

\- Automatic pagination

\- Extract quotes, authors, and tags

\- Export collected data to CSV

\- Compatible with Excel

\- HTTP error handling

\- Request timeout protection

\- Custom website URL input



\## Technologies



\- Python

\- Requests

\- BeautifulSoup4

\- CSV

\- HTML parsing



\## How to Run



Install the required dependencies:



```bash

pip install -r requirements.txt



Run the scraper:



python scraper.py





Enter the website URL when prompted.





The collected data will be saved to:



quotes.csv
